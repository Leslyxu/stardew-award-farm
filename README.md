# 星露奖杯农场 · 赛事导航（私有仓库）

面向中小学美术老师的星露谷像素风赛事导航工具。单文件离线可用，也可选部署到 GitHub Pages。

## 隐私说明（重要）
- 本仓库为 **私有（private）**，仅仓库所有者可见源代码。
- 若启用 GitHub Pages，生成的网站是**公开**的（任何人持链接即可访问）。要"只自己看"，请直接用 `index.html`（离线打开 / 微信发送），**不要开启 Pages**。
- 如需对外公开分享，再开启 Pages，并可加一层密码门禁。

## 使用
- 直接双击打开 `index.html` 即可使用（数据内置，离线可用）。
- 「我的资料 / 勾选 / 投稿包」只存在你浏览器本地，不上传任何服务器。

## 更新数据
1. 编辑 `data.js`（赛事 / 白名单 / 教研前沿 / 工具箱 / 评审专家）。
2. 运行 `python3 build_single.py` 重新生成单文件 `index.html`。
3. （可选）`git add -A && git commit && git push` 推回本仓库。

数据版本见 `data.js` 顶部 `DATA_VERSION`（当前第 15 版，2026-11-02）。
