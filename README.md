## 有一件事我不替你做

作品必须由学生 / 本人真实完成，最终提交与署名要你本人确认。这不是能力不够——上面这些赛事明文规定「禁止虚构、杜撰和抄袭」「代笔、高仿取消资格并列入黑名单」，部分还要求寄送原作、学校审核、实名与原创承诺。[红线和原文](submit.md)。本工作台做的是：评分表 → 框架草稿 → 材料清单 → 填好的内容 → 通知 → 打开通道，**只留最后「确认并提交」那一下给你**。
